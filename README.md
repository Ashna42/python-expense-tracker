
# Python Expense Tracker

A simple command-line expense tracker developed using Python. It allows users to manage their daily expenses by adding, viewing, and deleting expense records while calculating total spending.

## Features

- Add new expenses.
- View all recorded expenses.
- Delete existing expenses.
- Calculate total spending.
- Menu-driven command-line interface.

## Technologies Used

- Python

## How to Run

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory.

3. Run the Python file:

   python main.py

## Concepts Practiced

- Python dictionaries
- Functions
- Loops
- Conditional statements
- User input and output
- Basic expense calculations
